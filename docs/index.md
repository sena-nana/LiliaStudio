# LiliaStudio

LiliaStudio 是面向 Windows 的世界观与角色逻辑工作台。

## 当前能力

- 本地项目、条目、角色、事件、公理和关系库。
- 搜索、图谱、时间线和 JSON 导入导出工作流。
- 可选 AI 提供商、提示词模板、文本分块、向量检索和 RAG 上下文包。
- 逻辑审计、角色成长、模拟、诊断和帮助工作流。

## 开始使用

```bash
npm install --global corepack@0.35.0
corepack enable pnpm pnpm install
pnpm dev
```

更多本地开发命令见[开发启动](./guide/development.md)。
