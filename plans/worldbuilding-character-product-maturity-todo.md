# 世界观与角色形象塑造中心成熟度待办

## 当前判断

- Ameya 的产品定位应是“本地优先的结构化世界观资料库 + 角色形象塑造中心 + 逻辑一致性 + 向量/RAG + Agent 推演”。
- 现有项目已经具备 Project、Entry、Character、Event、Axiom、Relation、关键词搜索、RAG chunk、AI provider、任务队列和样例审计/模拟等基础。
- 当前角色能力仍偏薄，只覆盖 `name / aliases / summary / appearance / goals / motivations / fears / faction / tags`；角色成长页还是空壳，trait delta 只有基础函数。
- 最大缺口不是页面数量，而是“角色作为创作中心”的闭环不足：形象、心理、关系、经历、语气、知识边界、成长变化和世界规则还没有统一建模。
- 后续真正实现角色中心时，需要新增或迁移 Character 数据契约，不能只在前端堆字段。

## 成熟世界观创作软件应具备的能力

- 资料库/Wiki：词条、人物、地点、组织、物品、种族、规则、章节/故事圣经、模板字段、标签、引用、反向链接。
- 创作规划：时间线、剧情线、章节/幕结构、角色弧线、系列规划、版本/草稿状态。
- 世界模型：地图/地点、阵营、资源、经济、政治、文化、历史、公理规则、因果链。
- 可视化：关系图谱、时间线、地点地图、角色成长曲线、冲突报告、上下文来源预览。
- 写作辅助：AI 问答、RAG 上下文包、逻辑审计、角色行为一致性检查、设定补完问题、改写建议。
- 生产能力：导入导出、备份恢复、离线可用、诊断、任务队列、设置、模板、可追溯报告。

## 成熟人物设计软件应具备的能力

- 角色档案：基础身份、别名、年龄/生日、身高体型、种族/职业、身份状态、阵营、标签、角色重要度、出场作品。
- 形象设定：外貌拆分字段、服装/配色、标志物、姿态、表情、视觉关键词、参考图、画廊、版本差分。
- 内核塑造：欲望、目标、动机、恐惧、创伤、价值观、底线、秘密、矛盾点、误信念、成长课题。
- 行为与语气：说话风格、常用词、决策习惯、压力反应、社交模式、禁忌行为、角色扮演测试问答。
- 关系网络：亲属、师徒、敌友、恋爱、组织归属、权力关系、关系强度、关系随事件变化。
- 成长弧线：阶段状态、关键事件、能力/性格变化、心理状态变化、弧线目标和完成度。
- 知识边界：角色知道什么、不知道什么、误解什么，避免 AI 或剧情让角色使用不该知道的信息。
- 世界联动：角色能力受世界规则限制，身份受组织/法律/文化影响，行为选择受事件经历和关系牵引。
- 创作辅助：角色访谈、设定补完问题、矛盾检查、角色一致性评分、对白风格检查、形象提示词生成。

## P0 待办：补齐基础创作闭环

- 完善对象工作台：支持地点、组织、物品、种族/族群、章节/剧情线等对象类型，避免所有内容塞进泛 Entry。
- 重构角色模型为“角色中心”：新增外貌结构、内核塑造、行为语气、关系摘要、成长阶段、知识边界等字段或扩展字段。
- 补齐模板字段系统：不同对象类型和角色类型有稳定字段、默认模板、可扩展字段和字段级显示规则。
- 强化角色工作台：角色列表支持重要度、阵营、标签、关系数、最近事件、成长状态筛选；角色详情页能集中查看档案、关系、事件、规则约束。
- 强化图谱：显示真实关系边，支持按关系类型、置信度、角色/阵营过滤，从节点跳转编辑，突出孤立角色和冲突关系。
- 强化时间线：支持角色维度筛选、角色参与事件、关系变化事件、成长阶段标记和剧情线分组。
- 补齐语义检索 UI：完成 T025-T028，形成“索引 -> embedding -> 语义搜索 -> 上下文预览”的路径。
- 实现 AgentChat 可用闭环：输入问题、选择项目/角色上下文、展示引用来源、保存回答为报告或任务，不自动改写用户资料。

## P1 待办：形成 Ameya 差异化能力

- 真实逻辑审计：从 Axiom、关系、事件和角色资料中抽取事实，输出冲突位置、影响范围、最小冲突集和修复建议。
- 角色成长闭环：事件参与记录产生 trait delta，持久化来源，角色成长页展示属性变化、关键事件和不一致提示。
- 角色一致性审计：检查行为是否符合动机、恐惧、价值观、关系、知识边界和世界规则。
- 角色访谈/扮演模式：Agent 基于角色资料和 RAG 上下文回答，明确引用来源，并提示资料缺口。
- 设定补完助手：针对角色自动提出缺失依赖，如成长动因、能力成本、社会身份、视觉标志、关系压力、剧情功能。
- 叙事模拟闭环：模拟基于项目资料、角色目标、阵营关系和规则生成多阶段报告；报告可保存、复制、对比。
- RAG 可解释性：每条 AI 输出展示来源对象、chunk、相似度/命中理由，支持用户排除来源后重跑。
